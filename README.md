## 🚀 Project Overview

This project is a Heart Disease Prediction Web Application built using Machine Learning and Flask.

It predicts whether a person is likely to have heart disease based on medical parameters like age, cholesterol, blood pressure, etc.

---

## 🧠 Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Render (Deployment)

---

## 📊 Features

- Simple and clean web interface
- User input form for patient details
- Real-time prediction
- Confidence score output
- REST API endpoint (/predict)
